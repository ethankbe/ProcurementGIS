# synonyms.txt - groups of words that mean the same thing in procurement notices.
#
# One group per line:   word = alternative, alternative, ...
# Every term in a group matches the others, in either direction. Lowercase.
# Lines starting with # are ignored. Edits are picked up without restarting.
# Words of 3 letters or fewer (pc, ink, tv) match whole words only, so "ink"
# does not match "inkjet" and "pc" does not match "pcs".
#
# Built from the item names and descriptions in items.csv. Item names are
# standard category titles (for example "Notebook computers", "Ink rolls"),
# while descriptions are free text ("LAPTOPS"), which is why these help.
# Keep groups tight; review them against your own data.
